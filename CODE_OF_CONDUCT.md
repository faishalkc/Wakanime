# Code of Conduct

## Our Goal

Wakanime is a personal open-source project shared to be useful to others. Everyone participating in issues, pull requests, and discussions is expected to keep interactions respectful, constructive, and welcoming.

## Expected Behavior

- Be respectful, patient, and considerate in all project interactions.
- Offer constructive feedback focused on code, design, and user experience—not individuals.
- Respect differing experience levels and viewpoints.
- Keep discussions relevant to the project and its scope.

## Unacceptable Behavior

- Harassment, personal attacks, insults, or derogatory remarks.
- Discrimination or exclusionary language of any kind.
- Trolling, spam, or intentionally disruptive behavior.
- Publishing private or sensitive information about others without permission.

## Scope

This Code of Conduct applies to all spaces associated with the Wakanime repository, including issues, pull requests, code reviews, and project discussions.

## Reporting

If you experience or witness unacceptable behavior, please report it to the repository maintainer through the contact or issue-reporting channels available on the project's hosting platform.

## Enforcement

The repository maintainer reviews reports in good faith and may take appropriate action—such as removing comments, closing issues or pull requests, or restricting participation—to keep the project space respectful.
